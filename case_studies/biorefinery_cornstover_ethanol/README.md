# Case study — Cornstover → ethanol biorefinery

Full techno-economic analysis of the canonical NREL cellulosic-ethanol biorefinery
via BioSTEAM's `biorefineries.cornstover` model.

**Applies:** Tiers 0–4, 8.

## Run
```powershell
python case_studies/biorefinery_cornstover_ethanol/cornstover_tea.py
```
