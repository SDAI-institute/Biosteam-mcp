# Case study — Optimize, then quantify uncertainty

The two-stage expert workflow: optimize a design against a metric, then run Monte
Carlo *at the optimum* to report the risk the project actually faces.

**Applies:** Tiers 4, 7, 8.

## Run
```powershell
python case_studies/optimization_uncertainty/optimize_then_uncertainty.py
```

## Files
| File | What |
|------|------|
| `optimize_then_uncertainty.py` | Runnable script |
| `optimize_then_uncertainty.ipynb` | Executed notebook |
| `results.md` | Optimization + uncertainty results |
