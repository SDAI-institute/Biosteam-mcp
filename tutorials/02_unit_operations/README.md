# Tier 2 — Unit operations

Equipment that transforms streams: built-in units, their design/cost results, and
how to write your own.

## Learning objectives
- Apply a `Reaction` with a conversion.
- Use built-in units (`HXutility`, `BinaryDistillation`) and read `design_results`
  and `purchase_cost`.
- Write a **custom `Unit`** subclass (`_N_ins` / `_N_outs` / `_run`).
- Recognize when a separation is limited by an **azeotrope**.
