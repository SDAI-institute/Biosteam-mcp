# Tier 4 — Techno-economic analysis (TEA)

Turn a simulated system into money: capital, operating cost, and the minimum
selling price.

## Learning objectives
- Subclass `bst.TEA` (implement `_FOC`; the rest default sensibly).
- Read FCI (capital), FOC + VOC (operating), NPV.
- Solve the **minimum selling price (MSP)** and read the cash-flow table.
- Run a one-variable price sensitivity.
- Know when IRR is/ isn't meaningful (capital intensity).
